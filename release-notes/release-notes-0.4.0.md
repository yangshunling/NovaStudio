## v0.4.0 — 2026-11-14

> 本版本聚焦数字员工安装、会话级模型切换、执行人选择与安装包稳定性。

### ✨ 新增功能

#### 数字员工一键安装

- 未安装时页面直接提供一键安装。
- npm 日志实时回显。
- 失败原因区分 npm 缺失、超时与 PATH 未刷新。
- 安装成功后自动切到配置视图。

#### 会话级模型切换

- 输入框旁新增模型下拉，可搜索。
- 选择写入会话，下一轮生效。
- 「跟随 Agent 默认」不传 `--model`。
- 不写回 `settings.json`。
- 上下文占用按所选模型重新计算。

#### 模型列表兼容与降级

- 兼容 Base URL 已带 `/v1`。
- 兼容误粘贴的完整接口地址。
- 兼容 `/anthropic` 兼容网关。
- 自动尝试多个候选地址。
- 不支持时允许手动输入模型 ID。

#### 执行人选择

- 自动化任务可选择执行人。
- 工作流节点可选择执行人。
- 支持默认「通用助手」。
- 通用助手走 Agent 全局配置。
- 运行前校验员工是否存在且启用。

#### 更新提醒与图片落盘

- 启动后自动检查更新。
- 侧栏显示红点并弹一次提醒。
- 关于页展示下载进度。
- 会话图片改为附件落盘。
- 按内容哈希去重，按需加载。
- 单条消息最多 8 张、约 20MB。

#### 外观与交互

- 外观新增界面字体预设。
- 上下文占用改为圆环读数。
- `#` 支持引用工作区外文件。
- Git 面板自动刷新状态。

#### 编辑保护

- 提示词切换前确认未保存修改。
- 技能抽屉关闭前检查未保存草稿。
- 异步保存不再串写其它条目。

### 🐛 修复

- 修复 0.3.0 启动黑屏。
- 修复打包后图标与版本信息缺失。
- 修复 Windows 窗口 / 任务栏图标不显示。
- 修复工作流撤销 / 重做异常。
- 修复周报切换周期后的旧结果残留。

### ⬆️ 升级说明

- 直接覆盖安装即可，历史数据保持可用。
- 旧消息中的 base64 图片仍可回放。
- 未选模型的会话继续使用 Agent 默认模型。
