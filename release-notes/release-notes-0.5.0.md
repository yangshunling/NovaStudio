## v0.5.0 — 2026-11-14

> 本版本升级 UI 2.0，换上全新的 Nova 昼夜皮肤，并让会话可以分享出去、被另一个会话引用。

### ✨ 新增功能

#### UI 2.0 · Nova 昼夜双皮肤

- 界面升级到 UI 2.0，「经典 · 昼 / 夜」更名为「Nova · 昼 / 夜」，夜间仍为默认皮肤。
- 两套皮肤共用同一套材质：内高光、倒角阴影与多层纸面，层次更清晰。
- 夜间改用深蓝灰画布与星蓝紫强调色，昼间为冷瓷纸面。
- 升级后自动沿用原来的明暗，无需重新选择。

#### 空会话入口

- 新会话首页改为品牌标记与展示衬线标题「Work is Agentic」。
- 起手式改为整行列表，窄窗口下也不再截断。
- 入口顶部增加一层弥散光，离开空态即消失。

#### 分享会话

- 会话「…」菜单新增「分享会话」，导出完整过程为 Markdown。
- 内容包含对话、思考过程与工具调用；工具长输出超限会截断并标注。
- 图片只记录数量，不把图片数据写进文件。
- 使用系统「另存为」选择保存位置。

#### 引用会话

- `#` 菜单新增「会话」分类，可引用另一个会话的完整过程。
- 引用只把原始记录文件的路径交给 Agent，由它自己决定读多少。
- 引用完成后可以继续输入自己的问题，两者一起发送。

#### 引用展示

- 用户消息里的引用改为图标加名称的块，不再显示整段引用指令。
- 重试会自动带上原来的引用。
- 引用加载期间切走会话，不会加到别的会话里。

### 🐛 修复

- 修复首条消息带引用时，会话标题变成引用指令的问题。
- 修复切换皮肤后设置里残留已移除主题的问题。
- 修复深色皮肤下远端分支与本地分支难以区分的问题。

### ⬆️ 升级说明

- 直接覆盖安装即可，历史会话、工作流与设置保持可用。
- 原「经典 · 昼 / 夜」已更名为「Nova · 昼 / 夜」，升级后自动沿用，无需重设。
- 分享与引用只读取会话记录，不会改动原会话。
