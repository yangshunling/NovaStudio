## v0.6.0 — 2026-11-16

> 本版本重塑全站设计语言，Agent 配置改为自动保存，并统一各页面的交互细节。

### ✨ 新增功能

#### 设计语言重塑

- 两套 Nova 皮肤重做配色，夜间为深空石墨配浅品牌蓝，昼间为冷瓷纸面配深蓝。
- 去掉渐变、光晕、噪点与毛玻璃，层次改由表面明暗、发丝线与中性阴影建立。
- 页头、列表、卡片与空态统一为同一套结构，各页面用低饱和分区色区分身份。
- 侧栏改为「Nova · Work is Agentic」品牌标记，导航更紧凑。

#### 配置与选择

- Agent 配置改动后自动写回本机，页头实时显示保存结果，保存失败会提示。
- 工作区与数字员工选择器支持搜索，模型菜单可直接键盘切换或输入自定义 ID。

#### 会话与工作区

- 空会话改为「从一个任务开始」，直接显示当前工作区、数字员工与模型。
- 会话列表按两行展示，执行中、等待授权与待发送一眼可见。
- 运行状态改为状态灯加计时；工作区面板可直接在资源管理器中打开目录。

### 🐛 修复

- 修复下拉菜单在切页后偶尔错位、会话列表悬停时操作按钮遮挡时间的问题。
- 修复数字员工卡片把系统提示词当作简介展示的问题。
- 修复用键盘回车选择工作区、数字员工或模型时重复触发的问题。

### ⬆️ 升级说明

- 直接覆盖安装即可，历史会话、工作流与设置保持可用。
- 外观沿用当前的明暗选择，升级后自动使用新配色。
- Agent 配置改为自动保存，原先的手动保存流程不再需要。
