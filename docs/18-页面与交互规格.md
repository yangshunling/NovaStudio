# 18 页面与交互规格

## 1. 全局布局

```
┌──────────┬────────────────────────────────────────────────────────┐
│ Sidebar  │ 主内容区（按 viewMode 切换）                            │
│ 240px    │                                                        │
│          │                                                        │
│ 功能     │                                                        │
│ 资产     │                                                        │
│ 运行时   │                                                        │
│ 设置     │                                                        │
└──────────┴────────────────────────────────────────────────────────┘
```

- 侧栏宽度 `--c-layout-sidebar`（默认 240px）；
- 顶栏高度 `--c-layout-header`（默认 56px）；
- 主内容最大宽度 `--c-layout-content`（默认 896px）；
- 侧栏头部：logo + 标题 + 昼夜切换；
- 侧栏分组：功能 / 资产 / 运行时 / 设置；
- 工作流徽标：活跃运行数 / 待审核数。

### 1.1 侧栏导航

| 分组 | 项 | 图标 |
|---|---|---|
| 功能 | 会话管理 | MessageSquare |
| 功能 | 终端管理 | SquareTerminal |
| 功能 | 任务中心 | Workflow |
| 功能 | 工作流 | Waypoints |
| 功能 | 触发器 | AlarmClock |
| 功能 | 数字员工 | Users |
| 资产 | SKILL | Sparkles |
| 资产 | MCP | Plug |
| 资产 | 知识库 | Library |
| 资产 | 工作区 | FolderKanban |
| 运行时 | Agent 配置 | Bot |
| 底部 | 设置 | Settings |

### 1.2 工作流徽标

- 无活跃运行：不显示；
- 有运行：`N 运行`；
- 有待审核：`N 待审`（强调色）。

侧栏每 3 秒轮询 `workflow:run:listActive`（仅在有活跃运行时），并订阅 `workflow:run:event` 去抖刷新；新出现待审核时 toast。

## 2. 会话管理（`chat`）

### 2.1 布局

```
┌──────────────┬────────────────────────────────────┬──────────────┐
│ 会话列表      │ 中间：对话 / 文件标签               │ 工作区文件面板 │
│ 268px        │                                     │ 240-320px    │
│              │                                     │ （可折叠）     │
└──────────────┴────────────────────────────────────┴──────────────┘
```

- 左侧 `SessionListPanel`；
- 中间 `CenterPane`：`CenterTabs` + `ChatArea` / `FilePreview`；
- 右侧 `WorkspacePanel`（`showWorkspace` 控制）。

### 2.2 会话列表

- 标题「会话」+ 数量；
- 右上「+」新建会话（只进入空态，不落库）；
- 分组：置顶 → 今天 → 昨天 → 本周 → 更早；组标题可点击折叠（状态记在 localStorage）；
- 置顶组按置顶时间倒序，置顶会话不再重复出现在时间组；
- 每行：运行旋转图标 / 状态点 + 标题；
- 当前会话高亮；
- 「…」菜单：置顶 / 取消置顶、重命名、新建终端、删除；
- 删除走全局确认框；
- 空态：引导直接输入。

### 2.3 对话区

- 顶栏：会话标题 + 工作目录路径 + 文件面板开关；
- 消息区：`AssistantMessageList`；
- 空态：
  - 未绑定工作区：「新对话」+ 引导；
  - 已绑定：「开始对话」+ 工作区名；
  - 历史回放中：进度条 + “历史记录正在恢复中”；
- 输入区：
  - 玻璃拟态 + 大圆角；
  - 已引用文件 chips（可移除）；
  - textarea（Enter 发送，Shift+Enter 换行，中文输入法回车不发送）；
  - 工作区选择器；
  - Agent 选择器（仅多个已安装 Agent 时显示；会话创建后锁定）；
  - 发送 / 停止按钮；
  - `@` 提及时弹出文件列表。

### 2.4 文件标签

- 标签栏只在有打开文件时出现；
- 「对话」标签 + 文件标签；
- 文件标签可关闭；
- 切换标签不卸载对话（`hidden`）。

### 2.5 工作区文件面板

- 顶部：标题 / 刷新 / 关闭；
- 文件树懒加载；
- Git 状态标记；
- 宽度可拖拽，持久化到 `localStorage`；
- 点击文件 → 中间标签打开。

## 3. 终端管理（`terminals`）

### 3.1 布局

```
┌──────────────┬──────────────────────────────┬──────────────┐
│ 工作区列表    │ 终端（xterm）                 │ 工作区文件面板 │
└──────────────┴──────────────────────────────┴──────────────┘
```

### 3.2 工作区列表

- 全部工作区；
- 有终端的工作区显示绿点 + 终端图标；
- 点击：已有终端则切换，没有则在该目录创建；
- 右键：打开终端 / 打开工作区 / 关闭终端；
- 没有工作区时整页空态，引导去工作区页。

### 3.3 终端

- 每个工作区最多一个终端；
- 所有 xterm 实例保持挂载，切换不重启；
- 顶栏：工作区名 / 路径 / 文件面板开关 / 重启；
- PTY 退出：显示退出码 + 重启入口；
- 字体固定系统等宽，字号独立设置；
- 剪贴板快捷键；
- 右侧文件面板可打开文件，预览覆盖在终端上方。

## 4. 任务中心（`automation`）

### 4.1 布局

三列看板：

```
┌──────────────┬──────────────┬──────────────┐
│ 待执行        │ 执行中        │ 已完成        │
│ 新建任务      │ 停止 / 重试   │ 详情 / 重试   │
└──────────────┴──────────────┴──────────────┘
```

> 代码注释写“三列”，但 `AutomationStatus` 有 4 个状态；实际看板把 failed 放在「执行中」列（失败态 + 手动重试），因此视觉上是三列。

### 4.2 待执行列

- 顶部「新建任务」；
- 卡片：指令摘要、工作区、Agent、创建时间；
- 可删除；
- 等待轮询器拾取。

### 4.3 执行中列

- `running`：脉冲状态、停止按钮、不可删除；
- `failed`：错误信息、重试、删除；
- 任务详情：跳转会话、查看对话。

### 4.4 已完成列

- 成功任务；
- 详情 / 重试 / 删除。

### 4.5 新建任务弹框

- 指令（多行）；
- 工作区（必选）；
- Agent（必选）；
- 提交后进入 pending。

### 4.6 详情抽屉

- 任务状态、时间、错误；
- 会话消息（复用 `MessageGroup`）；
- 跳转到会话页。

### 5.2 工作流编辑器

布局：

```
┌──────────────┬────────────────────────────────────────────┐
│ 节点面板      │ 顶栏：返回 / 名称 / 保存 / 运行              │
│ 开始 / 结束   │                                            │
│ 数字员工列表   │ 画布（可拖拽 / 缩放 / 平移）                 │
│              │ 选中节点 → 右上角配置面板                    │
│              │ 底部：调试状态栏（运行中）                    │
```

#### 顶栏

- 返回（有未保存修改时确认）；
- 名称（按文字宽度伸缩）；
- 「未保存」徽标；
- 工作区选择（编辑归属）；
- 撤销 / 重做；
- 自动布局 / 适应画布；
- 保存；
- 运行 / 调试；
- 运行记录。

#### 左侧节点面板

- 开始 / 结束 / 执行节点；
- 数字员工列表，点击加入已绑定该员工的节点。

#### 画布

- 节点 240 × 124；
- 16px 网格吸附；
- 对齐参考线；
- 拖拽空白平移；
- 滚轮缩放（0.35–2）；
- 从右侧端口拖线；
- 选中连线可删除 / 改连；
- Shift / Ctrl 多选；
- 整组拖动 / 删除；
- Delete 删除；
- 节点状态色（调试时）；
- 校验问题标在节点上。

#### 节点配置面板

- 名称；
- 绑定员工；
- 任务详情；
- 失败策略：停止 / 跳过 / 重试 + 次数；
- 审核门禁：自动 / 人工 + 最大修改轮数；
- 删除节点。

#### 调试面板

- 进度、当前节点（并行多个）、耗时、错误；
- 等待审核时直接通过 / 驳回 / 要求修改并填备注；
- 终止；
- 打开完整运行详情；
- 节点状态实时变色。

### 5.3 运行详情

布局：

```
┌──────────────┬────────────────────────────────────────────┐
│ 节点列表      │ 选中节点：状态 + 对话                       │
│              │                                            │
└──────────────┴────────────────────────────────────────────┘
```

- 左侧节点列表：名称、状态、尝试 / 轮次；
- 右侧：
  - 页签：对话 / 结果 / 产物文件 / 提示 / 执行信息；
  - 对话按 attempt / round 分组；
  - 运行中合并实时事件快照；
  - 审核按钮（等待审核时）；
  - 产物文件可预览 / 打开 / 打开目录；
  - 提示页展示 warning / 重试 / 审批记录；
  - 执行信息展示 `execution.md`。
- 顶部：运行状态、来源、时间、耗时、错误、继续运行 / 取消 / 删除。

### 5.4 运行记录列表

- 工作区级 / 工作流级共用；
- 表格：状态、来源、开始、完成、耗时；
- 筛选：来源 / 状态；
- 操作：详情、重跑、继续运行、删除；
- 点击详情进入运行详情页。

### 12.1 布局

- 左侧 Agent 列表（当前只有 Claude Code）；

## 13. 设置弹框

分区：

1. 文字大小：全局 12–16px，聊天记录独立；
2. 终端：字号 11–20px；
3. 自动化并发数 1–10；
4. 轮询间隔；
5. 单次运行超时；
6. 应用更新：当前版本、检查、下载进度、重启安装；
7. 关于：应用名、版本、Electron、Chromium、Node、平台、架构、是否打包。

> 皮肤切换在侧栏头部昼夜按钮，不在设置弹框。

## 14. 交互通用规则

1. 危险操作必须二次确认（删除会话 / 工作区 / 工作流 / 运行 / 技能 / MCP / 知识库）。
2. 菜单贴近视口边缘时收拢。
3. 外部点击 / Esc / 滚动 / resize 关闭菜单。
4. 表单错误就地展示，不用阻塞弹框。
5. 运行中禁用会产生冲突的操作（切换工作区、删除运行、重复开始）。
6. 空态必须给出下一步行动（新建 / 管理工作区 / 安装 Agent）。
7. 加载态用骨架或进度条，不用空白页。
8. 所有可点击元素有 title / aria-label。
9. 中文输入法回车不触发发送。
10. 颜色 / 字号 / 间距只用 token，不硬编码。
