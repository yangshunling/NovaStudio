# 18 页面与交互规格

## 1. 全局布局

```
┌──────────┬────────────────────────────────────────────────────────┐
│ Sidebar  │ 主内容区（按 viewMode 切换）                            │
│ 240px    │                                                        │
│          │                                                        │
│ 个人     │                                                        │
│ 工程     │                                                        │
│ 资产     │                                                        │
│ 运行时   │                                                        │
│ 设置     │                                                        │
└──────────┴────────────────────────────────────────────────────────┘
```

- 侧栏宽度 `--c-layout-sidebar`（默认 240px）；
- 顶栏高度 `--c-layout-header`（默认 56px）；
- 主内容最大宽度 `--c-layout-content`（默认 896px）；
- 侧栏头部：标语图「Work is Agentic」，无图标、无昼夜切换；
- 侧栏分组：个人 / 工程 / 资产 / 运行时，底部固定设置入口；
- 工作流徽标：活跃运行数 / 待审核数；待办徽标：未完成数量。

### 1.1 侧栏导航

| 分组 | 项 | 图标 |
|---|---|---|
| 个人 | 会话管理 | MessageSquare |
| 个人 | 待办事项（未完成角标） | ListTodo |
| 工程 | 工作区 | FolderKanban |
| 工程 | 工作流（运行 / 待审徽标） | Waypoints |
| 工程 | 触发器 | AlarmClock |
| 工程 | 自动化任务 | Workflow |
| 工程 | 数字员工 | Users |
| 资产 | MCP | Plug |
| 资产 | SKILL | Sparkles |
| 资产 | 提示词 | MessageSquareText |
| 资产 | 知识库 | Library |
| 运行时 | Agent 配置 | Bot |
| 底部 | 设置 | Settings |

### 1.2 工作流徽标

- 无活跃运行：不显示；
- 有运行：`N 运行`；
- 有待审核：`N 待审`（强调色）。

侧栏通过 `lib/workflow-run-sync.ts` 统一订阅 `workflow:run:event` 去抖刷新（与工作流页、运行记录页共用一套订阅与兜底轮询，仅存在活跃运行时才每 10 秒兜底）；新出现待审核时 toast。待办角标由 `todos:changed` 推送。

## 2. 会话管理（`chat`）

### 2.1 布局

```
┌──────────────┬────────────────────────────────────┬──────────────┐
│ 会话列表      │ 中间：对话 / 文件标签               │ 工作区文件面板 │
│ 268px        │                                     │ 240-320px    │
│              │                                     │ （可折叠）     │
└──────────────┴────────────────────────────────────┴──────────────┘
```

- 左侧 `SessionListPanel`；
- 中间 `CenterPane`：`CenterTabs` + `ChatArea` / `FilePreview`；
- 右侧 `WorkspacePanel`（`showWorkspace` 控制）。

### 2.2 会话列表

- 标题「会话」+ 数量；
- 右上「+」新建会话（只进入空态，不落库）；
- 分组：置顶 → 今天 → 昨天 → 本周 → 更早；组标题可点击折叠（状态记在 localStorage）；
- 置顶组按置顶时间倒序，置顶会话不再重复出现在时间组；
- 每行：运行旋转图标 / 状态点 + 标题；
- 当前会话高亮；
- 「…」菜单：置顶 / 取消置顶、重命名、新建终端、删除；
- 删除走全局确认框；
- 空态：引导直接输入。

### 2.3 对话区

- 顶栏：会话标题 + 工作目录路径 + 文件面板开关；
- 消息区：`AssistantMessageList`；
- 空态：
  - 未绑定工作区：「新对话」+ 引导；
  - 已绑定：「开始对话」+ 工作区名；
  - 历史回放中：进度条 + “历史记录正在恢复中”；
- 输入区：
  - 玻璃拟态 + 大圆角；
  - 工具授权条（当前会话有待处理请求时显示，可展开完整入参）；
  - 待发送图片缩略图（可逐张移除）；
  - `#` 引用 chips（文件 / 工具 / 技能 / 知识库，可移除）；
  - textarea（Enter 发送，Shift+Enter 换行，中文输入法回车不发送；纯图片消息允许正文为空）；
  - 工作区选择器；
  - Agent 选择器（仅多个已安装 Agent 时显示）；
  - 员工选择器（`@` 与它共用会话绑定）；
  - 权限模式选择器（default / auto / acceptEdits / plan / dontAsk / bypassPermissions）；
  - 图片选择按钮；支持粘贴、拖入、文件选择；
  - 发送 / 停止按钮；
  - `#` 弹出内容引用列表，`@` 弹出已启用员工列表。

### 2.4 文件标签

- 标签栏只在有打开文件时出现；
- 「对话」标签 + 文件标签；
- 文件标签可关闭；
- 切换标签不卸载对话（`hidden`）。

### 2.5 工作区文件面板

- 顶部：标题 / 刷新 / 关闭；
- 文件树懒加载；
- 只监听根目录与当前展开目录，收到 `workspace:changed` 后只重拉脏目录；
- Git 状态标记；
- 宽度可拖拽，持久化到 `localStorage`；
- 点击文件 → 中间标签打开。

## 3. 终端标签（会话页内）

终端没有独立侧栏页面，而是会话页中间区域的标签：

- `CenterTabs` 列出「对话」、已打开文件与终端标签；
- 从工作区页或会话「…」菜单「新建终端」创建；默认同一工作区复用一个终端，`新建终端` 可强制多开；
- 所有 xterm 实例保持挂载，切换标签 / 侧栏页面都不重启 PTY；
- PTY 退出后显示退出码与重启入口；
- 字体固定系统等宽，字号独立设置；主题固定纯黑，不随皮肤切换；
- 剪贴板快捷键：`Ctrl/Cmd+V`、`Ctrl+Shift+V`、`Shift+Insert` 粘贴，`Ctrl+Shift+C`、`Ctrl+Insert`、`Cmd+C` 复制选中；
- 右侧工作区文件面板可打开文件，预览覆盖在终端上方；
- 关闭标签直接销毁 PTY，关闭多个终端前二次确认。

## 4. 自动化任务（`automation`）

### 4.1 布局

四列看板：

```
┌──────────┬──────────┬──────────┬──────────┐
│ 待执行    │ 执行中    │ 需处理    │ 已完成    │
│ 新建任务  │ 停止      │ 失败/停止 │ 详情/重试 │
└──────────┴──────────┴──────────┴──────────┘
```

> 侧栏标签为「自动化任务」；失败与被停止的任务独立成「需处理」列，避免误以为还在跑。

### 4.2 待执行列

- 顶部「新建任务」；
- 卡片：指令摘要、工作区、Agent、创建时间；
- 可删除；
- 等待轮询器拾取。

### 4.3 执行中列

- `running`：脉冲状态、停止按钮、不可删除；
- 任务详情：跳转会话、查看对话。

### 4.4 需处理列

- `failed`：错误信息、重试、删除。

### 4.5 已完成列

- 成功任务；
- 详情 / 重试 / 删除。

### 4.6 新建任务弹框

- 指令（多行）；
- 工作区（必选）；
- Agent（必选）；
- 提交后进入 pending。

### 4.7 详情抽屉

- 任务状态、时间、错误；
- 会话消息（复用 `MessageGroup`）；
- 跳转到会话页。

- 节点 240 × 124；

## 14. Agent 配置（`agents`）

### 12.1 布局

- 左侧 Agent 列表（当前只有 Claude Code）；
- 右侧配置表单；
- 未安装：只展示安装引导卡片（一键安装 + 实时日志 + 重新检测 + 手动命令兜底），
  不渲染任何配置项；安装并检测通过后才切换到配置视图（先安装、后配置）。

### 12.2 配置分区

- 接入：Base URL、API Key、鉴权方式、apiKeyHelper；
- 模型：默认模型 + Fable / Opus / Sonnet / Haiku 别名（名称 + 上下文）；
- 权限：`permissions.defaultMode`；
- 网络：HTTPS_PROXY / NO_PROXY / API_TIMEOUT_MS；
- 运行限制：最大输出 token / 最大思考 token / 禁用非必要流量；
- 云厂商：Bedrock / Vertex / Foundry 专属字段；
- 保存写回 `~/.claude/settings.json`。

### 12.3 模型列表

- 按 Base URL / Key 尝试 `/v1/models`，失败时兜底 `/models`；
- 接入点未提供模型列表接口时（404 / 405）降级为中性提示，
  用户仍可手动输入模型 ID，不影响保存与运行；
- 下拉选择；
- `apiKeyHelper` 模式不可拉取，提示原因。

## 15. 设置弹框

左侧分组导航 + 右侧卡片式内容，五个独立面板：

1. **通用**：默认 Agent、默认工作目录；
2. **外观**：皮肤（经典·昼 / 经典·夜）、界面字体（系统默认 / 微软雅黑 / 苹方 / 思源黑体 / 宋体 / 楷体）、界面字号、聊天字号；
3. **终端**：终端字号；
4. **自动化**：并发数 1–10、轮询间隔、单次运行超时；
5. **关于与更新**：应用名、版本、Electron / Chromium / Node、平台、架构、是否打包；检查更新、下载进度、重启安装。

> 皮肤切换在「设置 → 外观」，侧栏不再保留昼夜切换按钮。

## 16. 交互通用规则

1. 危险操作必须二次确认（删除会话 / 工作区 / 工作流 / 运行 / 技能 / MCP / 知识库）。
2. 菜单贴近视口边缘时收拢。
3. 外部点击 / Esc / 滚动 / resize 关闭菜单。
4. 表单错误就地展示，不用阻塞弹框。
5. 运行中禁用会产生冲突的操作（切换工作区、删除运行、重复开始）。
6. 空态必须给出下一步行动（新建 / 管理工作区 / 安装 Agent）。
7. 加载态用骨架或进度条，不用空白页。
8. 所有可点击元素有 title / aria-label。
9. 中文输入法回车不触发发送。
10. 颜色 / 字号 / 间距只用 token，不硬编码。
