# 25 工作区设计语言 —— Workbench Ledger

> 只定义「侧栏 → 工作区」这一页的 UI 元素与组件，不改动全局皮肤。
> 页面像一本工作台台账：发丝线分组、28px 行高、等宽数字、状态字母方块；
> 层级由排版与留白建立，而不是卡片、药丸和投影。

## 1. 范围

- 工作区列表（`WorkspacesView`）
- 工作区控制台头部与页签（`WorkspaceConsole`）
- 文件树与预览页签（`FilesTab`）
- Git 工具栏、变更列表、diff、提交区、提交历史（`GitTab`）

实现位置：

- `components/workspaces/workspace.css`：`ws-*` 局部样式层
- `components/workspaces/workspaceUi.tsx`：工作区共用空态
- 组件只引用 `--c-*` token，不写死颜色 / 字号 / 圆角

---

## 2. 原则

1. **线先于框。** 分组用 1px 发丝线与留白，不套卡片；工作区页没有投影卡片。
2. **一行一件事。** 变更文件 28px、提交记录 28px、文件树 28px；信息密度高但不拥挤。
3. **状态用字母，不用药丸。** 16px 字母方块承载 U / M / D / R / C / !，颜色只是辅助。
4. **机器信息用等宽。** 路径、分支、diff、计数全部 `tabular-nums` / mono。
5. **强调色只做当前位置。** 选中项 = 2px 左轨 + 浅色底；不做整行实心色块。
6. **控件安静。** 工具按钮默认无边框、无底色；hover 才浮出浅层底。
7. **空态是排印。** 36px 描边图标方块 + 标题 + 一句可执行的说明，不套大圆角卡片。

---

## 3. 布局

```
┌──────────────┬──────────────────────────────────────────────┐
│ 工作区列表    │ 控制台头部 56px：图标 / 名称 / 路径 / 分支 / 动作 │
│ 268px        ├──────────────────────────────────────────────┤
│              │ 页签 42px：文件 / Git（下划线）                  │
│ 行 44px      ├──────────────────────────────────────────────┤
│              │ Git 工具栏 28px 控件 + 发丝线                   │
│              ├───────────────┬──────────────────────────────┤
│              │ 变更 340px     │ diff / 空态                   │
│              │ 分组 + 提交历史 ├──────────────────────────────┤
│              │               │ 提交区（输入 + 墨水主按钮）      │
└──────────────┴───────────────┴──────────────────────────────┘
```

- 左列表宽度跟随 `--c-layout-session-list`（当前 268px）；变更栏 340px；
  页面内边距跟随 `--c-space-section`（当前 20px）。
- 滚动只发生在：工作区列表、变更列表、提交历史、diff。
- 提交区固定在右栏底部，不随 diff 滚动。

## 4. 元素规格

### 4.1 工作区列表

- 行：44px，`padding 8px`，4px 圆角；选中 2px 左轨 + accent-soft 底。
- 图标：26px 方形描边容器，文件夹图标使用 agent-amber。
- 名称：14px / 500；路径：11px mono / muted，单行截断。
- 头部：11px 字距 0.08em 的小标 + 18px 描边计数。
- 底部：一条发丝线 + 本地目录 / 按需读取说明。

### 4.2 控制台头部

- 高度跟随 `--c-layout-header`（当前 56px），1px 底发丝线；图标 28px 描边方块。
- 标题 16px / 600；路径 11px mono。
- 分支控件：28px 高、4px 圆角、`surface-2` 底、1px 描边；
  内含分支图标、分支名、↑n / ↓n、变更数。
- 动作：28px 方形图标按钮，默认无底无边。

### 4.3 页签

- 42px 高，1px 底发丝线。
- 选中：墨色文字 + 2px 强调色下划线；计数是 16px 描边方块。

### 4.4 工具栏

- 28px 控件；按钮默认无边框，hover 浅层底。
- 组之间用 1px × 16px 竖线分隔；批量操作靠右。
- 分支切换、拉取、推送、全部暂存、全部取消、刷新各占一个明确入口。

### 4.5 变更分组与文件行

- 分组头：28px，`surface-2` 底板 + 1px 内描边，把分组从文件列表里托出来；
  标题保持 11px / 600 / 0.06em 小标，右侧计数；冲突组标题用错误色。
  分组名前是三态全选框（空 / 部分 / 全选），只改变勾选，不执行 Git 操作。
- 文件行：28px；左侧 14px 方形勾选框，右侧 16px 状态字母方块。
- 勾选即选中，不等于暂存：先勾选多个文件，再由分组头
  「暂存 / 取消暂存 n」或工具栏「暂存选中 n」一次执行整批；
  点击文件名只加载 diff，绝不改动暂存区。
- 文件名 13px；父路径 11px mono / muted；单行截断。
- 选中行：2px 左轨 + accent-soft 底；hover 仅换浅层底。
- 行尾操作：hover 时出现 20px 图标——普通文件是「丢弃」，冲突文件是「标记已解决」；
  批量丢弃放在工具栏，不放进分组头。

### 4.6 Diff

- 头部 34px：路径 mono + 「打开文件」文字按钮。
- 统计条：`+n` / `-n` / 行数，等宽数字。
- 正文：11px mono，22px 行高；新增 / 删除行使用 diff 语义色与 2px 内阴影左轨。
- hunk 头用强调色浅底；元信息行用 muted。

### 4.7 提交区

- 一张 `surface-2` 纸：1px 描边、6px 圆角、无投影。
- 头部：11px 小标「提交信息」+ 已暂存计数。
- 输入：无边框 textarea，行高 1.6；整张纸在 focus-within 时描边转强调色并出现 2px 浅环。
- 底部：发丝线 + 左提示、右主按钮（提交）。
- 错误：1px 错误色描边 + 错误浅底，不弹窗。

### 4.8 提交历史

- 行 28px；左侧 20px 图形轨（竖线 + 圆点）。
- 传出的提交用强调色轨；已推送段用 muted 轨；HEAD 用空心圆。
- 引用徽标：18px 高、2px 圆角、mono 10px；本地分支用强调色，远端用紫，标签用琥珀。

### 4.9 文件树与预览

- 文件树行 28px，按层级缩进 14px；目录变更数用 16px 计数方块。
- 预览页签 36px：下划线式，选中 2px 强调色；每个页签可单独关闭。

### 4.10 进行中操作

- merge / rebase / cherry-pick / revert / bisect / am 进行中时，在 Git 工具栏上方出现横幅。
- 26px 描边图标方块 + 标题（rebase 带 2/4 进度）+ 一句说明 + 「继续 / 中止」。
- bisect 没有 continue，只提供「结束」（`git bisect reset`）。
- 横幅存在时锁定分支切换、新建分支、pull / push、丢弃；merge 仍允许直接提交。

### 4.11 空态

- 36px 描边图标方块 + 16px 标题 + 13px 说明；可选一个主操作。
- 不套大圆角卡片、不使用插画与渐变。

---

## 5. 与全局设计系统的关系

- 只使用既有 token；不新增皮肤，不改全局 `ui-*` 原语。
- 局部样式统一 `ws-` 前缀，避免影响其它页面。
- 若将来要把这套语言推广到全站，再把 `ws-*` 中稳定的部分提升为全局原语。
